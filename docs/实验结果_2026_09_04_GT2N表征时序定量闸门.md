# 实验结果：GT2N 表征时序定量闸门（2026-09-04）

## 结论

当前 ngspice 加载官方 BSIM-CMG 111.2.1 OSDI 的 GT2N 五端适配网表能够稳定完成反相器瞬态求解，但未通过公开标准单元表征库的数值闸门。因此，GT2N 目前只可表述为“接口可运行、组合逻辑一致、有限瞬态可计算”，不可表述为“在 ngspice 中物理正确仿真”。

## 固定条件与可复核输入

被测单元为 `gt2_6t_inv_x1_w13_svt`，典型角为 0.7 伏、25 摄氏度。参考是 GT2N 自带 `gt2_6t_w13_svt_tt_0p7v25c.lib` 的 8×8 延迟与转换时间表；被测网表为原始单元经既有四端至五端适配后的版本，模型为 Berkeley 官方 BSIM-CMG 111.2.1 OSDI，仿真器为 ngspice-44+。所有输入、适配器、OSDI 和仿真器散列已写入 `summary.json`。

## 结果

| 指标 | 数值 |
|---|---:|
| 时序点数 | 128 |
| 正常退出进程 | 128 / 128 |

| 延迟误差不超过 10% | 0 / 128 |
| 转换时间误差不超过 10% | 0 / 128 |
| 数值闸门通过 | 0 / 128 |
| 严格闸门通过 | 0 / 128 |
| 延迟相对误差：平均 / 中位 / 最大 | 23.17% / 24.72% / 32.84% |
| 转换时间相对误差：平均 / 中位 / 最大 | 27.07% / 27.31% / 35.07% |
| 单进程峰值常驻内存 | 11588 至 11756 千字节 |
| 实验总耗时 | 9.48 秒 |

最小负载、2 皮秒输入上升沿的输出下降延迟为 5.863 皮秒，参考表为 8.730 皮秒，误差 32.84%；对应输出下降转换时间为 3.815 皮秒，参考为 5.852 皮秒，误差 34.82%。全体点的误差方向相同：当前适配仿真普遍快于公开表征值。输入下降的 64 点延迟误差平均为 22.31%，输入上升的 64 点平均为 24.03%，因此差异并非单一边沿的测量符号错误。

每个任务都报告模型卡中的 `FECH` 未识别并被忽略；这是先前已知、但仍未解除的模型接口差异。另有一条轻微负向越轨，最小值为负 8.469 毫伏，超过计划设定的负 7 毫伏下限。它不改变“全部数值误差失败”的结论。

## 指标边界与后续动作

本实验没有从 ngspice 导出可审计的方程维数、非零元、线性迭代数或残差，故这些指标为不适用；不以猜测替代测量。为遵守精简项目约束，结果目录只保留 128 份逐点网表与测量值、聚合摘要和一份代表性原始日志；可由网表完全复生的波形及冗余调试输出已移除。

该负结果排除了“只差缺少参考波形”的乐观解释：公开表征数据已显示当前适配在动态数量级上存在系统偏差。下一步不应继续无依据删改 GT2N 参数；应转向具备原始参考可比较证据的候选，当前为 FreePDK3 的功能性候选，或在有 HSPICE 的环境中对 GT2N 原始模型卡做同条件交叉仿真。
