# 数据生成链路补齐与最小闭环记录（2026 年 8 月 21 日）

## 结论

本次补齐了从空数据目录开始的最小复现链路：生成无工艺库依赖的测试网表、调用原生程序导出线性系统轨迹与 Jacobian、训练并导出 warmup 向量、训练稀疏学习型 Schwarz 预条件子、运行稀疏 GMRES 验证，以及运行冻结状态 warmup 对照。旧服务器没有可用 C 编译器，因此本次兼容性试跑使用旧 PALS 目录中已有的原生二进制；该二进制只作为只读验证，不作为提交内容。

## 新增与修复

- `pypath/data_generation/generate_reproducible_dataset.py`：固定随机种子生成二极管/电阻/电容测试网表，导出轨迹、Jacobian、warmup 向量和工作点清单。
- `pypath/data_generation/warmup_tools.py`：新增最小 warmup 训练与向量导出；修复 `STATE0_OUT` 完整状态向量与 `rhsold` 线性系统维数不一致导致的样本全部丢弃问题，目标优先选择同维的 `WP_OUT` 或 `NEW`。
- `pypath/data_generation/run_minimal_reproduction.py`：新增一键串联入口。
- `pypath/utils/run_frozen_warmup_stage_benchmark.py`：新增 `--include-zero-gmin`，允许最小原生数据集中只有零 gmin 工作点时进行严格冻结核验；默认行为仍跳过零 gmin。
- `pypath/proposer/config.py`：支持通过 `WMPC_NGSPICE_EXECUTABLE` 指定新服务器上的原生二进制。
- 生成统计修正为分别记录轨迹文件数、Jacobian 文件数和去重后的 warmup 阶段数。

## 试跑命令

```bash
cd /home/ZhangLexin/PALS/wmpc
export WMPC_PYTHON=/home/ZhangLexin/miniconda3/envs/PALS_env/bin/python3
export WMPC_NGSPICE_EXECUTABLE=/home/ZhangLexin/PALS/release/src/ngspice
export PYTHONPATH=.
$WMPC_PYTHON pypath/data_generation/run_minimal_reproduction.py \
  --output-root results/runs/minimal_reproduction_smoke \
  --num-circuits 1 --node-count 4 --seed 9 --circuit-id 0 \
  --timeout-sec 60 --warmup-epochs 3 --preconditioner-epochs 2
```

在具备 C 编译器的服务器上，先在 `wmpc` 内编译得到 `build/src/ngspice`，再把 `WMPC_NGSPICE_EXECUTABLE` 指向该路径即可。生成数据和运行结果默认只留在 `results/runs/`，不提交到仓库。

## 可核验指标

- 原生导出：1 个电路，152 个工作点；轨迹文件 152 个，Jacobian 文件 152 个，去重 warmup 阶段 72 个。
- warmup：训练样本 153 个；最终入口按 `(电路、时间、gmin)` 去重，导出 72 个阶段入口向量。此前未去重试跑曾导出 153 个文件，该行为已修正。
- 预条件子训练：1 个工作点，训练 2 轮，检查点成功生成。
- 稀疏 GMRES：两种模式均严格成功；方程维数 12，非零元 29，稀疏存储估计 400 字节，稠密存储估计 1152 字节；两者迭代数均为 8，真实相对残差约 `4.429172570189556e-09`。
- 冻结 warmup：冷启动与 warmup 两臂共 2 个任务，2/2 严格成功，1 个严格配对工作点；冷臂 GMRES 总迭代 77，warmup 臂 78，当前差异为 -1，不宣称收益。
- 通用无标准单元网表没有可识别语义块，预条件子覆盖率为 0，因而本次只验证接口、精度和回退安全性，不宣称学习型 Schwarz 优势或内存超过 50% 的论文结论。

## 后续服务器执行顺序

1. 编译原生程序并设置 `WMPC_NGSPICE_EXECUTABLE`。
2. 运行 `run_minimal_reproduction.py` 做单电路冒烟。
3. 检查 `generation_summary.json`、稀疏 GMRES `summary.json`、冻结 warmup `aggregate/summary.json`。
4. 更换为真实当前网表和节点映射后，再训练语义块预条件子并进行联合评测；历史生成数据不能直接复用。
5. 扩展到批量任务前，按实验计划记录样本数、严格成功数、方程维数、非零元、内存、耗时、迭代数、残差和失败分类。
