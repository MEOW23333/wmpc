# 二至五纳米候选库证据审计（2026-09-04）

## 结论

当前可公开取得的候选中，FreePDK3 是唯一通过本项目基本器件和反相器严格功能闸门的三纳米库；它适合后续 ngspice 功能性实验。没有任一候选同时具备可在当前服务器运行的模型链、原始工艺卡的公开参考波形，以及与参考逐点比较的证据，因此没有候选达到“物理正确已证明”的等级。GT2N 是唯一明确的公开二纳米完整库，但其公开表征时序表已显示当前 ngspice 五端适配存在系统动态偏差，不能作为正确物理仿真使用。

## 证据等级

“接口可加载”只表示模型进入 ngspice；“功能通过”要求 NMOS、PMOS、反相器直流和瞬态均满足有限性、极性和逻辑闸门；“物理正确”还要求同一模型卡、网表、激励和温度下，与原始 HSPICE 或作者公开波形逐点定量比较。三者不能互相替代。

## 原始参考材料审计

GT2N 的工作树中保存了本项目生成的 ngspice 波形和组合测试结果，但没有其原始 HSPICE 的 `.lis`、`.tr0`、`.mt0` 或等价参考波形。FreePDK3 的示例 `HSPICE_default/outputs.xml` 记录输入、输出名称和仿真目录，却不含波形采样值。GT3 提供表征库中的时序与功耗表，能够支持后续功能和时序范围检查，但不是与当前晶体管级派生卡同条件的原始瞬态参考。
SCCAD-3nm-PDK 只提供 BSD 三条款模型卡，没有 Verilog-A、HSPICE 数值输出或参考波形；其最小闸门的完整诊断见 实验结果_2026_09_04_SCCAD三纳米模型卡闸门.md。

BSIM-CMG 107、108 发布包虽包含官方 HSPICE 基准输出，但当前 OSDI 对官方 108 反相器卡有实例几何参数不兼容和初始化核心转储，不能将其当作通用执行器的物理校准通过证据。详细失败链见 `实验结果_2026_09_04_BSIMCMG108官方参考校准.md`。

当前 `PALS` 目录内只发现 ngspice 可执行文件；未发现 HSPICE、Xyce、Spectre 或可用容器运行时，也未发现 GT2N、GT3、FreePDK3 的原始 HSPICE 数值结果。PKP3 所需的新版 OpenVAF 预编译程序又要求高于本机的运行库版本，且本机没有 Rust、`gcc`、`make` 工具链可在本地重建。故“在有 HSPICE 或较新运行库的服务器上执行”是外部环境条件，不是当前项目代码可自行消除的缺口。

## 检索边界与后续顺序

本次公开仓库检索发现的新增条目主要是 FreePDK3 的版图适配或流程封装，未发现独立、可执行并有参考数据的二至五纳米紧凑模型库；该结果只描述本次检索，不能宣称互联网中不存在其他库。下一步优先级为：第一，在具备 HSPICE 的环境中生成 GT2N 与 FreePDK3 的同条件参考；第二，在运行库较新的环境中编译 PKP3 的原始 PHIMO-Fusion 模型；第三，才扩大到标准单元全库、跨规模和 warmup 实验。论文或报告中应把 FreePDK3 写成“功能性兼容候选”，不写成工艺已认证。

## 增量公开检索（2026-09-04）

本次以 GitHub 仓库检索接口查询“2nm PDK”“3nm PDK”“5nm PDK”和“GAAFET PDK BSIM-CMG”。二纳米仅返回 GT2N；三纳米直接模型候选仍为 SCCAD-3nm-PDK 与 FreePDK3；五纳米只发现 ASAP5 的版图工具封装。其余条目是 KLayout 封装、课程工程或汇总索引，不含可审计的紧凑模型和参考数据，未纳入候选表。

GT2N 上游提交仍为 `699e2c10b2b494a120745515f59df8815f4f0175`，与当前审计版本一致；SCCAD-3nm-PDK 上游提交仍为 `0b24880a87edac1034475870512d0ec6894ecc0b`，也没有新增材料。FreePDK3 上游提交仍为 `2a6dd3c6c34a36c232b6c9320e5d05b6afac24c7`，其仓库只含 HSPICE 配置和 `outputs.xml` 的输出名称定义，仍未提供数值波形、时序表或测量文件。因此本次检索没有产生可替代 GT2N 的新增物理候选，PKP3 仍是唯一值得在较新工具链上继续接入的三纳米候选。
