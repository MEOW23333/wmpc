# 实验结果：SCCAD 三纳米候选库静态审计（2026-09-04）

## 结论

SCCAD-3nm-PDK 是有效的新三纳米模型候选，不能仅归为版图或流程资料。仓库内有前端、背端两个唯一的 `3nm_GAA.sp` BSIM-CMG 111 模型卡，四个工具目录副本中两两完全相同，且模型文件头明确为 BSD 三条款许可。仓库没有 Verilog-A 模型、HSPICE 数值输出或其他公开波形参考，故尚不具备物理正确性校验条件；下一步只可做 ngspice 接口和功能闸门。

来源为 `https://github.com/sjung366/old-repositoru.git`，提交 `0b24880a87edac1034475870512d0ec6894ecc0b`，仓库说明名为 SCCAD-3nm-PDK。使用无检出浅克隆读取 2854 条文件路径，临时克隆仅 81007 字节，未下载历史和版图对象。路径筛选命中四个模型卡及四个自动曲线拟合脚本；未命中 `.va`、`.vams`、`.lis`、`.tr0`、`.mt0`、`.raw` 或其他原始参考波形文件。

四份模型卡中，前端卡散列为 `3427920a167efaeae52b3056e3e556578a511f4ff255869f1387a9a649da57e8`，背端卡散列为 `4b8814cd6e0188cf5620880fa555776fc4f2f3a94d7696814652ce3ca27a2b79`。Cadence 与 Synopsys 目录中的同一前端或背端文件逐字相同，因此后续只需保留两份。

## 模型接口判断

两卡均含 NMOS_LVT 与 PMOS_LVT，标为 `LEVEL=72`、`version=111`、`GEOMOD=5`、`DEVTYPE=1/0`，并使用 `WGAA/TGAA/NGAA` 几何字段。它们的接口形态与 GT3 的 BSIM-CMG 111 GAAFET 卡相近：当前 ngspice 不能直接解释 `level=72`，需由 OSDI 接管；`WGAA/TGAA/NGAA` 与 `HFIN/TFIN/NFIN` 的对应关系必须作为派生假设单独审计。模型卡中还含 `CAPMOD=1` 等物理非零字段，不能为了消除警告而静默删除。

因此本候选的当前等级为“可接入审计”，不是“功能通过”或“物理正确”。最小静态证据位于 `results/candidates/sccad3_static_audit_20260904/`。
