## 有编译器的服务器上的步骤

1. 安装 C/C++ 编译器、自动配置工具、自动构建工具、代码生成工具、数学库开发文件和命令行读入库开发文件。
2. 进入 WMPC 根目录，执行 ./autogen.sh。
3. 创建独立构建目录并执行：

       mkdir build
       cd build
       ../configure --without-x --disable-xspice --disable-openmp --disable-cider --with-readline=no --prefix=本地安装目录
       make -j8

4. 编译完成后，原生程序位于 build/src/ngspice。把该路径写入实验配置，不要使用旧 PALS 的二进制。
5. 使用 PALS_env 环境运行 Python 单元测试和侧车导出工具。
