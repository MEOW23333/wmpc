# 实验结果：SCCAD 三纳米模型卡闸门（2026-09-04）

## 结论

SCCAD-3nm-PDK 的前端、背端模型卡可以经派生接口在当前 ngspice 中完成 NMOS、PMOS 和反相器计算，但不能作为正确仿真候选。六项派生任务均有有限数值且逻辑翻转正确，却全部出现未识别参数和 OSDI 对非零物理参数的钳位或修正，严格成功为 0/6。原始 HSPICE 形式的两个反相器任务均在 `.LIB` 语句处失败。

## 固定输入与派生

来源和静态审计见 `实验结果_2026_09_04_SCCAD三纳米候选库静态审计.md`。保留前端、背端两份 BSD 三条款模型卡。派生将模型类型改为 `bsimcmg_va`，去除 HSPICE 的 `level`、`version` 和模型括号，映射 `WGAA/TGAA/NGAA` 为 `HFIN/TFIN/NFIN`，以 `NFIN=3` 取代重复的源卡 `NFIN=1`，并把 `GEOMOD=5` 映射为 `GEOMOD=2`。PMOS 类型使用 BSIM-CMG 111 OSDI 已有 GT3 证据的 `TYPE=-1`。这些都是接口假设，不是原工艺语义的证明。

## 数值结果

前端卡的 NMOS 供电支路电流绝对值随栅压从 6.82121 pA 增至 63.1080 µA；PMOS 从 9.66338 pA 增至 57.2583 µA。反相器直流在输入 0 V 时输出 0.7000002 V，在 0.7 V 时输出 26.53166 nV；400 ps 瞬态四个采样值为 0.7000000、7.005666 µV、0.6999928、7.005665 µV。

背端卡的对应 NMOS、PMOS 电流绝对值分别从 4.66116 pA 至 46.8496 µA、从 6.70752 pA 至 42.5223 µA。反相器直流同样从 0.7000002 V 切换至 24.56191 nV；瞬态采样为 0.7000000、0.1949923 mV、0.6998410、0.1949923 mV。六项均正常结束，单管耗时 0.01 秒、反相器耗时 0.02 至 0.03 秒，最大常驻内存 5772 至 5940 KiB。直接求解日志未导出方程维数、非零元和残差，记为不可得。

## 严格失败原因

每个派生模型卡均把非零 `CAPMOD=1` 记为未识别并忽略；`COREMOD=0` 也被忽略。OSDI 还报告并改变或钳位多个参数：NMOS 的负 `PDIBL2` 与负 `PTWG`，PMOS 的负 `PDIBL2`、小于下界的 `MEXP`，背端 PMOS 还有低于下界的有效宽度。上述不是纯语法警告，说明执行模型已偏离源卡参数语义。模型没有公开的 HSPICE 波形，故即使没有这些警告也不能证明物理等价。

结论分级为“接口可运行且逻辑功能正确、物理绑定和严格稳定性失败”。本候选不加入当前准确仿真测试集，也不应作为论文中的先进工艺精度证据。最小复核文件位于 `results/candidates/sccad3_osdi_gate_20260904/`。
