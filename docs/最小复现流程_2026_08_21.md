# WMPC 最小复现流程（2026 年 8 月 21 日）

## 代码结构

- `src/`：原生求解器源码，包含稀疏 GMRES、Schwarz 预条件子和数据导出接口。
- `pypath/data_generation/`：生成测试网表、导出训练数据、训练与导出 warmup、运行最小闭环。
- `pypath/preconditioner/`：学习型 Schwarz 模型、块划分、训练器和单元测试。
- `pypath/utils/`：稀疏 GMRES、冻结 warmup、联合验证和侧车工具。
- `results/`：只保存可提交的小型检查点与结果摘要；`results/runs/` 为本地运行产物，不应提交。
- `docs/`：实验计划、实验记录、研究结论和构建说明。

编译原生程序：

```bash
./autogen.sh
mkdir build
cd build
../configure --without-x --disable-xspice --disable-openmp \
  --disable-cider --with-readline=no --prefix=$PWD/install
make -j8
cd ..
export WMPC_NGSPICE_EXECUTABLE=$PWD/build/src/ngspice
```

## 一条命令完成最小闭环

```bash
$WMPC_PYTHON pypath/data_generation/run_minimal_reproduction.py \
  --output-root results/runs/minimal_reproduction \
  --num-circuits 1 \
  --node-count 4 \
  --seed 7 \
  --circuit-id 0 \
  --timeout-sec 120 \
  --warmup-epochs 10 \
  --preconditioner-epochs 5
```

执行顺序为：

```text
生成网表
→ 原生导出轨迹与 Jacobian
→ warmup 训练
→ warmup 向量导出
→ 预条件子训练
→ 稀疏 GMRES 验证
→ 冻结 warmup 验证
```

## 分步执行

生成数据：

```bash
$WMPC_PYTHON pypath/data_generation/generate_reproducible_dataset.py \
  --output-dir data/repro \
  --num-circuits 1 --node-count 4 --seed 7
```

训练并导出 warmup：

```bash
$WMPC_PYTHON pypath/data_generation/warmup_tools.py train \
  --trajectory-dir data/repro/trajectory \
  --output-dir results/runs/warmup_train \
  --epochs 10 --hidden-dim 32 --seed 7

$WMPC_PYTHON pypath/data_generation/warmup_tools.py generate \
  --trajectory-dir data/repro/trajectory \
  --checkpoint results/runs/warmup_train/warmup_mlp.pt \
  --output-dir results/runs/warmup_vectors
```

训练预条件子：

```bash
$WMPC_PYTHON pypath/preconditioner/train_learned_schwarz.py \
  --netlist-dir data/repro/generated_netlists \
  --trajectory-dir data/repro/trajectory \
  --circuit-ids 0 \
  --output-dir results/runs/preconditioner \
  --run-tag circuit0_step0 \
  --step-offset 0 --max-steps-per-circuit 1 --max-samples 1 \
  --epochs 5 --lr 1e-4 --hidden-dim 64 --gaussian-probes 2 \
  --initial-guess-mode rhsold --block-mode generic --seed 7
```

验证预条件子：

```bash
$WMPC_PYTHON pypath/utils/sparse_gmres_prototype.py \
  --trajectory-dir data/repro/trajectory \
  --circuit-id 0 --max-steps 1 \
  --backend scipy_sparse \
  --modes row_sum,learned_schwarz_v1_sparse \
  --output-dir results/runs/preconditioner_eval \
  --netlist-path data/repro/generated_netlists/0.sp \
  --learned-schwarz-checkpoint \
    results/runs/preconditioner/circuit0_step0/learned_schwarz_v1.pt \
  --apply-gmin-diagonal --use-rhsold-as-x0
```

最小通用测试网表用于验证完整性、精度和接口，不代表真实标准单元语义块实验。论文级结论必须换成当前真实网表、节点映射和同源二进制重新训练与评测。
