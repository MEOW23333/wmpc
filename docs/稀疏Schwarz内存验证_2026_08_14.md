# 稀疏学习型 Schwarz 预条件子精度与内存验证计划

日期：2026-08-14  
状态：用户已确认执行  
代码分支：\`hard_block_minimal_push\`

## 目标

验证 \`learned_schwarz_v1_sparse\` 在保持预条件器数值输出与原稠密 V1 一致的前提下，避免全局稠密矩阵，并在目标规模上实现超过 50% 的内存节省。

## 固定输入

- 检查点：\`experiments/core_block_repro_10x10/learned_schwarz/smoke_norm_v1/learned_schwarz_v1.pt\`
- 数据集：\`precondition_experiments/10x10\`、\`precondition_experiments/10x100\`、\`precondition_experiments/100x100\`
- 每个电路：只选第一个可用 Newton 步。
- 初值：零向量。
- 求解器：GMRES，\`restart=100\`，\`max_iters=500\`，\`rtol=1e-8\`，\`atol=1e-10\`。
- 块设置：\`cell_core_plus_onehop_boundary\`，最小块大小 2，最大块大小 32。
- BLAS 线程数：1。

## 阶段一：同一矩阵精度与内存核对

- 电路：\`10x10\` 的电路 0、首个 Newton 步。
- 比较：原稠密 V1 与 \`learned_schwarz_v1_sparse\`。
- 数值门槛：同一探测向量上的相对二范数差不超过 \`1e-12\`。
- 内存门槛：新实现的保守峰值估算相对原 V1 全局双精度稠密矩阵节省超过 50%。
- 记录：两种实现的隔离进程峰值常驻内存、矩阵维数、非零元数、块数、覆盖率、局部 LU 因子字节数、输出差和门槛判定。

## 阶段二：三种规模真实求解复核

- 运行方案：只重跑当前新实现 \`learned_schwarz_v1_sparse\`。
- 对照方案：复用同一固定任务表上的既有 \`row_sum\`、\`semantic_cell_core_sparse\`、\`local_sparse_schur_sparse\` 结果。
- 原因：既有结果已在同一矩阵、同一零初值和同一残差口径下落盘；重跑 100x100 的旧 Schur 路线会重复已知的 5000 秒超时，不增加对新实现的证据。
- 样本数：每种规模 20 个电路，共 60 个新任务。
- 并行度：\`10x10=20\`，\`10x100=20\`，\`100x100=2\`。
- 单任务超时：5000 秒。
- 失败策略：每个子任务独立落盘；超时、构造失败、GMRES 未收敛和真实残差失败分别统计；阶段一未通过则不进入阶段二。

## 成功判定与汇报指标

严格成功条件为：

\[
\frac{\lVert Ax-b\rVert_2}{\max(\lVert b\rVert_2,\epsilon)} < 10^{-8}.
\]

每种规模至少汇报：

- 样本数、成功数、失败数、超时数和失败原因。
- 方程维数、非零元数、初值策略和块覆盖率。
- 平均与分位数：GMRES 迭代、构造时间、求解时间、总时间、隔离进程峰值常驻内存。
- 最终真实相对残差及其分位数。
- 新实现的 \`sparse_peak_estimated_bytes\`、\`dense_v1_global_matrix_bytes\` 和 \`estimated_peak_memory_saving_ratio\`。
- 相对既有基线的差异，以及是否满足精度与内存门槛。
