# CellWarm DAC 论文包

该目录是一份面向 DAC 研究论文轨道的英文 LaTeX 稿件。正文按 DAC 最新已公开的 2026 初投稿规则排版：ACM 双栏模板，正文最多 6 页，另加 1 页且只放参考文献，双盲评审。DAC 2027 征稿页发布后还需复核页数、日期和生成式工具披露条款。

## 填入实验数据

1. 由最终汇总脚本生成所有指标，并替换 `RESULT_MACROS.tex` 中的 `XX`。
2. 导出 `figures/newton_cdf.pdf` 与 `figures/scale_speedup.pdf`。
3. 核对表格、正文宏与两张图来自同一份原始汇总。
4. 不得手工填写无法映射到原始结果、分析脚本和运行清单的数字。

## 编译

```bash
latexmk -pdf main.tex
```

## 投稿前硬检查

- `main.pdf` 必须满足 6 页正文加 1 页参考文献；第 7 页只能出现参考文献。
- 日志中不得有未定义引用或文献。
- 所有字体必须嵌入，两张数据图必须为矢量 PDF。
- 删除 PDF 元数据中的作者、单位、资助和机器路径。
- 把作者信息和致谢留到录用后的终稿。
- 全文生成式工具披露必须与 DAC 当届政策和作者的真实使用方式一致。
